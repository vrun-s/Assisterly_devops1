Assignment 4 Overview

Dignified Care Coordination, Powered by HTML5 APIs

Welcome to the Assisterly Shift Planning Console. This webpage showcases two powerful client-side HTML5 technologies: the Drag & Drop API for interactive caregiver allocation, and Web Storage (both persistent localStorage and transient sessionStorage) for local audit logging.

Using the visual widgets below, coordinators can assign caregiver profiles directly to schedule shifts via intuitive dragging gestures. Additionally, coordinators can register session-specific and long-term diagnostic variables to inspect read/write serialization in real-time.

Technical Specifications

HTML5 APIs Explained

Drag & Drop API

Provides native browser drag support. Handled via dragstart, dragover, dragleave, and drop events, allowing complex object mapping without large external JS libraries.

Local Storage API

Saves key-value pairs persistently in the user's browser with no expiration date. Ideal for user profiles, theme toggles, and permanent app preferences.

Session Storage API

Saves data temporarily for a single browser tab session. The data is destroyed immediately when the tab is closed, ensuring security for transient operational variables.

Operations Manual

Frequently Asked Questions & Support

Interactive instructions on client-side data allocation and memory management.

Simply click and hold down on any of the colored Caregiver cards under the "Available Caregivers" deck. Drag the card towards the Morning, Afternoon, or Night shift boxes. You will see the target boxes highlight with a dashed border. Release the click while hovering over the target box to drop it inside. The slot will automatically save this caregiver assignment.

You can drag the caregiver card out of its shift box and drop it into the "Trash Zone" (the red box located at the bottom-left of the scheduler) to unassign it. The card will be restored to the available caregivers list and removed from browser storage.

Local Storage: Stores your Coordinator Profile (Name, Dept, and PIN) permanently. If you refresh the page or close your browser, the data remains.

Session Storage: Stores the temporary "Shift Dispatch Notes". These notes survive basic page refreshes, but are completely wiped once you close the browser tab, keeping temporary hand-over notes secure.

Type values into the form fields, assign a caregiver to a shift, and click "Save Data". Then, click the "Retrieve Data" button. The diagnostic display console will query the browser's APIs and render a table showing the stored information. You can also view this in browser Developer Tools under the Application tab.
